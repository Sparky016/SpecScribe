## Landmines
- **Lens Studio MCP never connects** in Claude Code (server sends bogus chunked framing). The user explicitly authorized `python scripts/lsmcp.py list|schema|call` despite `spectacles-lens/AGENTS.md`'s no-raw-HTTP rule (also in memory). Token: `re.sub(r'^Bearer\s+','', json.load(open('.mcp.json'))['mcpServers']['lens-studio']['headers']['Authorization'])`. `lsmcp.py call` truncates output at 12 000 chars — import `lsmcp.rpc` directly for big results. `scripts/lsq.py '<graphql>' [scene-graphql]` wraps runtime/editor GraphQL. Set `PYTHONIOENCODING=utf-8` (tool descriptions contain non-cp1252 chars).
- **Unsaved Lens edits**: scene changes made via `scene-graphql` live in the editor until saved. `useAuthoredBoardPose`, `isPhysicalHardware`, palette/board poses were unsaved earlier; `Scene.scene` now shows modified, but confirm with the user.
- **`requireAsset` needs string literals** at the call site (resolved at compile time) — passing a path variable fails with "Cannot find asset". `ButtonIcon.applyButtonIcon` takes a loader closure for this reason.
- **Preview camera ≠ what you see**: CameraModule in preview returns a 480x548 centre crop of the board. That's why the capturer uses `simulatedTexture` (the take clip) with capturer `demoMode=true` — preview-only setting; real glasses would use the camera.
- **Preview media clock is independent of Lens restarts**: `RunAndCollectLogsTool` restarts the Lens but not the Preview panel video. Re-applying the same `sourcePath` is a no-op; bounce `PreviewPanelTool setConfig` to an image (`listSources().images[0]`) then back to the clip, then restart the Lens (auto_take.py does this).
- **PreviewInteractTool**: pinches/hovers by `name`. One simulated hand randomly stops responding (left or right, varies); auto_take.py falls back to the other hand. Earlier "every pinch restarts the Lens" was a symptom of the old giant board collider, not the tool.
- **Old board collider bug** (fixed): `box.size` is local units × object scale; cm values made a ~148 m wall that stole pinches and dragged the board (overlay is a child of the backplate). Don't revert to cm sizes.
- **Never wipe on an empty vision answer**: an omitted `visible_vertices` + `has_meaningful_change` wiped the live overlay in a take. Only `board_is_empty=true` may clear. Keep that rule.
- **Delta-based vision was abandoned** on purpose: errors accumulated (stale "S"/"NT" nodes, slivers). Full snapshot + reconcile is the design; `apply_delta` remains only for legacy/no-key paths and old tests.
- **Free-form x/y from Gemini were imprecise** (0.08–0.10 off); Gemini's native `box_2d` (0–1000, [ymin,xmin,ymax,xmax]) + `board_box_2d` gave ≤0.02. Node types are only service/decision/database/terminal (a client is `terminal`).
- **Pre-existing test failures** (not this session): Lens `SpatialInterfaceManager.ts is under 300 lines` + Task 48 (file was already 304), Task 52 orb tests (user's sign change in `RaisingHandAgentController.ts`); backend `test_list_meetings_returns_summaries_newest_first` (live Supabase paging), live-Gemini flakes in `test_agents.py::test_websocket_ask_agent_research_pull`, `test_spec_generator.py::test_rest_api_finalize_and_ask_flow`.
- **Background servers**: stopping a `npx`/wrapper task can orphan the real server on the port; check `netstat -ano | grep :PORT` and kill the child. Killing the *user's* dev server process was denied by the auto-mode classifier.
- **Dashboard login**: middleware only picks up `.env.local` changes after a full dev-server restart.
